# ARENA — Student Competitive Learning & Placement-Preparation Platform

> **"Learn. Practice. Compete. Get Placement Ready."**

ARENA is a unified student competitive learning and placement-preparation platform designed to bring coding, aptitude, communication, technical preparation, assessments, mock interviews, and resume preparation into one cohesive ecosystem.

> [!IMPORTANT]
> **Current Status: Milestone 45 — Project Completion**

---

## 🚀 Technology Stack

### Frontend
- **Framework**: React.js (v18+) with TypeScript
- **Build Tool**: Vite
- **Routing**: React Router DOM (v6)
- **Icons**: Lucide React
- **Styling**: Modern Vanilla CSS (Design System with CSS Variables)

### Backend
- **Framework**: Python FastAPI
- **ASGI Server**: Uvicorn
- **Settings & Validation**: Pydantic v2 & Pydantic Settings

### Database & Authentication (Foundation)
- **Firebase**: Firebase SDK v10 (Authentication & Cloud Firestore abstraction)
- **AI Engine**: Google Gemini API
